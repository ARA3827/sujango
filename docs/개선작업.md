# 수장고(sujango.com) 개선 작업 지시서

이 문서는 지금까지 나온 피드백을 **안티그래비티에 단계별로 지시할 수 있게** 정리한 것입니다.
각 단계는 아래 네 부분으로 되어 있어요.

- **왜 하나요**: 작가님이 이해하기 위한 설명
- **할 일 목록**: 이 단계에서 바뀌어야 할 것 전부 (체크하면서 확인)
- **안티그래비티 지시문**: 회색 상자 안의 내용을 그대로 복사해서 붙여 넣으면 됩니다
- **확인 방법**: 작업이 끝난 뒤 직접 눈으로 확인할 것

> **사용법 요약**
> 1. 이 파일을 프로젝트 폴더 안 `docs/개선작업.md`로 넣어두세요.
> 2. 안티그래비티 새 대화를 열 때마다 **[공통 규칙]**을 먼저 붙여 넣고, 그다음 해당 단계 지시문을 붙여 넣으세요.
> 3. **한 대화에 한 단계만** 진행하세요. 끝나면 확인하고, 문제없으면 다음 단계로.
> 4. `[ ]` 안의 대괄호 표시는 작가님이 직접 채워 넣어야 하는 부분입니다.

## 공통 규칙 (모든 단계 시작 전에 먼저 붙여 넣기)

```
이 프로젝트는 1인 미술 작가를 위한 웹 서비스 "수장고(sujango.com)"야.
docs/개선작업.md 파일에 단계별 개선 작업이 정리되어 있어. 다음 규칙을 반드시 지켜줘.

1. 작업을 시작하기 전에 현재 상태를 Git에 커밋해줘. 커밋 메시지는 "○단계 작업 전 백업"으로.
2. 내가 지시한 단계의 범위만 수정해. 범위 밖의 파일이나 기능은 건드리지 마.
3. 코드를 수정하기 전에, 어떤 파일의 어느 부분을 어떻게 바꿀지 목록과 계획을 먼저 보여주고 내 승인을 받은 뒤에 진행해.
4. 기존 디자인(색상 #0F172A 남색, 폰트, 여백, 레이아웃)은 지시가 없는 한 그대로 유지해.
5. 사용자가 브라우저에 저장한 데이터(localStorage, IndexedDB 등)의 구조나 키 이름은 절대 바꾸지 마. (6단계에서만 별도 지시)
6. 모바일, 태블릿, PC 화면에서 모두 깨지지 않게 해줘.
7. 작업이 끝나면 바뀐 파일 목록, 바뀐 내용 요약, 내가 직접 확인해야 할 화면을 정리해서 알려줘.
8. 지시 내용이 실제 코드 구조와 맞지 않거나 애매하면, 추측해서 진행하지 말고 먼저 나에게 물어봐.
```

## 0단계. 준비

**왜 하나요**
작업 중 문제가 생겨도 언제든 지금 상태로 되돌릴 수 있게 저장 지점을 만드는 단계입니다.

**할 일 목록**
- [ ] 이 파일을 프로젝트 폴더 `docs/개선작업.md`로 넣기
- [ ] 현재 사이트 상태 백업(커밋)
- [ ] 현재 사이트의 주요 화면을 스크린샷으로 저장해 두기 (나중에 비교용)

**안티그래비티 지시문**

```
docs/개선작업.md 파일을 읽고 전체 내용을 파악해줘. 아직 코드는 수정하지 마.
1. 현재 프로젝트 상태를 Git에 커밋해줘. 메시지는 "개선 작업 시작 전 원본 백업".
2. 이 프로젝트의 구조를 간단히 설명해줘: 메인페이지, 대시보드, 각 도구(영감 노트, 작가노트&SNS, 전시 캡션 출력기, 서류·출강 스튜디오, 창작 가계부, 작품 수장고), 요금 페이지가 각각 어느 파일에 있는지.
3. 사용자 데이터를 어디에 어떤 방식으로 저장하는지(브라우저 저장소인지, 클라우드인지) 알려줘.
4. 개선작업.md의 각 단계를 진행할 때 예상되는 위험한 부분이 있으면 미리 알려줘.
```

**확인 방법**

## 1단계. 문구 수정 (가장 안전한 작업)

**왜 하나요**
화면 구조는 그대로 두고 글자만 바꾸는 작업이라 망가질 위험이 가장 적습니다. 동시에 효과는 큽니다. 지금 문구에는 서로 충돌하는 내용(고해상도 보관인데 압축 강조), 과장으로 읽힐 수 있는 표현("영원히 안전한", "영구 보존"), 작가가 이해하기 어려운 개발 용어("2-Depth", "11 9s", "Signed URL")가 섞여 있어요.

> **작가님이 먼저 확인할 것**
> 실제로 원본을 무손실로 보관하는 건 **Pro 이상**이고, 무료 플랜은 **압축본만** 저장하는 게 맞나요? 아래 문구는 그 전제로 썼습니다. 실제 동작이 다르면 문구를 실제에 맞게 고쳐서 지시하세요.

**할 일 목록**

메인 히어로
- [ ] 상단 배지 문구 교체
- [ ] 서브 문구 교체 (출강 서류, 정산, 원본 보관이 첫 화면에 보이게)
- [ ] 메인 버튼 문구 교체 + 보조 버튼 추가 (보조 버튼 추가는 2단계에서 디자인과 함께 진행해도 됨)

비교 카드

- [ ] 오른쪽 카드 제목·항목 교체 ("영원히 안전한", "다이어트 압축", "디지털 서고" 제거)

기능 소개 섹션
- [ ] 섹션 제목·설명 교체 ("골칫거리" 제거)
- [ ] 6개 카드 문구 교체 및 **순서 변경** (작품 수장고가 맨 앞)
- [ ] 카드 태그 교체 ("프라이빗 영구 보존" → "원본 보관", "AI 글 생성" → "초안 작성")

후기 섹션
- [ ] 실제 이용자 후기가 아니라면 **섹션 숨기기** (삭제 말고 숨김. 나중에 진짜 후기로 다시 켤 수 있게)

마지막 CTA
- [ ] 마지막 섹션 문구 추가/교체

대시보드
- [ ] "클릭 시 2-Depth 상세 작업공간으로 진입합니다" 문구 교체

창작 가계부
- [ ] 세무 참고용 안내 문구 추가

용어 통일
- [ ] 사이트 전체에서 "서고", "디지털 서고", "작품 아카이브 서고" → "수장고"로 통일

## 2단계. 디자인 정리

**왜 하나요**
문구가 정리되면 이제 눈에 보이는 부분을 다듬습니다. 아이콘과 이모지가 겹쳐 산만해 보이는 문제, 헤더에 직접 만드신 붓글씨 로고가 없는 문제, 히어로 글자가 이미지와 겹치는 문제를 해결합니다.

> **작가님이 먼저 준비할 것**
> - 붓글씨 로고 파일 (배경이 투명한 PNG 또는 SVG). 가능하면 아래 세 가지 버전
>   - 원본 질감 버전 (큰 화면용)
>   - 획을 정리한 단순화 버전 (작은 크기, 파비콘용)
>   - 흰색 반전 버전 (남색 배경용)
> - 실제 서비스 화면 캡처 이미지 (대시보드나 캡션 출력 결과 화면). 히어로 이미지 속 태블릿 화면에 넣을 용도

**할 일 목록**
- [ ] 모든 카드 제목 앞 이모지 제거 (메인 기능 카드, 대시보드 도구 카드, 가계부 탭 버튼, 요금제 카드 안 박스)
- [ ] 헤더 로고를 팔레트 아이콘 + 영문 → 붓글씨 '수장고' 로고 + 작은 영문 'Sujango'로 교체
- [ ] 헤더 옆 "수장고" 회색 배지는 로고와 중복되니 제거
- [ ] 히어로 서브 문구가 오른쪽 이미지와 겹치지 않게 처리
- [ ] 히어로에 보조 버튼 "기능 둘러보기" 추가 (기능 소개 섹션으로 스크롤)
- [ ] 히어로 이미지 속 태블릿 화면을 실제 서비스 화면으로 교체 (또는 이미지 자체를 실제 화면 캡처 중심으로 교체)
- [ ] 요금제 카드 세 개를 넓은 화면에서는 한 줄로, 좁은 화면에서는 세로로 쌓이게 정리
- [ ] Pro 카드에 "추천" 배지 추가
- [ ] 전시 캡션 출력기의 미리보기 제목 줄 정리 (제목과 가위 안내 문구가 비좁게 겹쳐 있음)
- [ ] 작가노트 화면의 "크기 / 규격" 라벨 줄바꿈 정리

**안티그래비티 지시문**

```
docs/개선작업.md의 2단계(디자인 정리)를 진행해줘. 색상과 폰트 체계는 그대로 유지해.

## 3단계. 버그 수정

**왜 하나요**
신규 회원 화면에 실제와 다른 숫자가 보이거나, 잘못된 값이 미리 들어가 있으면 서비스 신뢰가 떨어집니다.

**할 일 목록**
- [ ] 대시보드 카드의 예시 숫자 제거 ("미수금 1,200,000원", "3점 준비") → 실제 데이터와 연동, 데이터 없으면 표시 안 함
- [ ] 전시 캡션 출력기: 작가명(영문) 칸에 한글 이름이 들어가는 문제
- [ ] 창작 가계부: 소득/세율 유형 드롭다운 글자 잘림
- [ ] 창작 가계부: 날짜 입력 칸이 옆 칸과 높이·위치가 안 맞는 문제
- [ ] 서류·출강 스튜디오: 강의계획서 입력칸이 예시 값으로 채워져 있는 문제 → 회색 placeholder로
- [ ] 다른 도구에도 예시 값이 실제 값처럼 채워진 칸이 있는지 점검
- [ ] 전시 캡션 출력기: "14대 표준 재료 선택" 라벨이 무슨 뜻인지 불분명 → 이해하기 쉬운 문구로

**안티그래비티 지시문**

```

1. 대시보드 도구 카드의 상태 배지
   - 창작 가계부 카드에 "미수금 1,200,000원", 전시 캡션 카드에 "3점 준비"가 보이는데, 실제 가계부와 캡션 화면에는 0원, 0점이야.

**확인 방법**

- 강의계획서 입력칸이 회색 안내 글씨로 바뀌었는지

## M단계. 모바일 화면 개선 (3단계 다음에 진행)

**왜 하나요**
휴대폰에서 보면 헤더가 세 줄을 차지하고, 한글이 글자 단위로 끊기고("몰입하세 / 요."), 상자 안에 상자가 겹쳐 글자 폭이 좁아집니다. 또 작가는 휴대폰을 주로 **기록**(작품 사진, 영감 문장, 영수증)에, PC를 **완성**(캡션 인쇄, 서류 작성)에 씁니다. 그래서 휴대폰에서는 빠르게 남기는 흐름을 가장 편하게 만드는 것이 목표예요.

이 단계는 두 부분으로 나뉩니다.
- **M-1. 화면 깨짐 수정**: 위험이 낮고 효과가 커서 바로 진행
- **M-2. 휴대폰 사용 흐름 개선**: 화면 구조를 바꾸는 작업이라 계획을 먼저 받기

**할 일 목록 (M-1. 화면 깨짐 수정)**
- [ ] 한글 단어 단위 줄바꿈 (사이트 전체)
- [ ] 헤더 한 줄로 줄이기 (로고 / 로그인·프로필 / 메뉴)
- [ ] 메인 히어로 제목 크기 조정, 휴대폰용 짧은 서브 문구
- [ ] 좌우 여백 줄이고 겹친 상자 걷어내기
- [ ] 배지·짧은 라벨이 줄바꿈되지 않게 ("총 0점 보관 중")
- [ ] 대시보드 빈 상태 정리 (중복 버튼·반복 문구 제거)
- [ ] "창작 행정 & 비즈니스 비서 도구" 제목 줄 정리
- [ ] 입력칸 글자 16px 이상 (아이폰 자동 확대 방지)
- [ ] 버튼·칩 터치 영역 44px 이상
- [ ] 국문/영문 나란히 있는 입력칸을 휴대폰에서 위아래로
- [ ] 숫자 칸(가격, 크기, 연도, 시간)에 숫자 키패드, 가격 자동 쉼표
- [ ] 옆으로 넘기는 탭·칩 (문서 탭, 캡션 스타일 탭, 재료 칩)
- [ ] 가계부 요약 카드 2×2, 장부 표를 카드 목록으로
- [ ] 메인 히어로 이미지 용량 줄이기

**할 일 목록 (M-2. 휴대폰 사용 흐름 개선)**
- [ ] 첫 로그인 시 활동명(작가명) 설정
- [ ] 하단 탭 바 (홈 / 작품 / ＋ / 서류 / 더보기)
- [ ] 가운데 ＋ 빠른 기록 (작품 사진 찍기 / 영감 문장 / 영수증 기록)
- [ ] 도구 화면 "입력 | 결과" 전환 탭 + 하단 고정 버튼
- [ ] 긴 입력 폼을 단계로 나누기 (캡션, 작가노트)
- [ ] 입력 중 자동 임시저장
- [ ] 작품 등록 시 카메라 바로 열기, 업로드 진행률, 실패 시 재시도
- [ ] 결과 복사 버튼 (작가노트·SNS 캡션)
- [ ] 캡션 미리보기에 "PDF 저장 / 공유하기" (휴대폰 기본 공유 창)
- [ ] 무료 플랜 기기별 저장 안내
- [ ] 요금 페이지 휴대폰 배치 (Pro 먼저 또는 플랜 탭)
- [ ] (5단계 이후) 홈 화면에 앱처럼 설치 (PWA)

**안티그래비티 지시문 (M-1. 화면 깨짐 수정)**

```
docs/개선작업.md의 M단계 중 M-1(화면 깨짐 수정)을 진행해줘. 휴대폰(가로 폭 360~430px) 기준으로 고치고, 태블릿과 PC 화면은 지금과 똑같이 유지해.

1. 한글 줄바꿈
   - 사이트 전체 기본 스타일에 word-break: keep-all을 적용해서 한글이 단어 단위로 줄바꿈되게 해줘.
   - 긴 영문 이름이나 URL이 화면 밖으로 넘치지 않게 overflow-wrap: anywhere도 함께 넣어줘.
   - 지금 "몰입하세 / 요.", "작가 / 님의", "드 / 립니다"처럼 끊기는 곳이 모두 해결됐는지 확인해줘.

2. 헤더
   - 휴대폰에서 헤더가 세 줄(로고 / 수장고 소개·이용안내 / 로그인·메뉴)로 되어 있어. 한 줄로 바꿔줘: 왼쪽 로고, 오른쪽 로그인 버튼(로그인 후에는 작은 프로필 원형 아이콘만)과 메뉴 버튼.
   - "수장고 소개", "이용안내" 링크와 "○○님의 수장고" 버튼은 메뉴 안으로 옮겨줘.
   - 헤더 높이는 56~64px 정도로.

3. 메인 히어로 (휴대폰)
   - 제목은 화면 폭에 맞게 글자 크기를 줄여서 두 줄로 깔끔하게 떨어지게 해줘: "작가님은 오롯이 / 창작에만 몰입하세요."
   - 서브 문구는 휴대폰에서만 짧은 버전으로 보여줘: "원본 보관부터 캡션, 출강 서류, 정산까지. 작가의 모든 기록을 한 곳에서."
   - 제목, 서브 문구, 버튼이 스크롤 없이 첫 화면에 보이게 해줘.
   - 배경 이미지는 휴대폰용으로 가로 폭 800px 이하의 가벼운 버전을 따로 쓰게 하고, 화면 아래쪽 이미지들은 스크롤할 때 불러오게(lazy load) 해줘.

4. 여백과 겹친 상자
   - 휴대폰에서 페이지 좌우 여백을 16px 정도로 줄여줘.
   - 메인 비교 카드, 대시보드 수장고 영역처럼 상자 안에 상자가 겹쳐 있는 곳은, 휴대폰에서 바깥 상자의 테두리·배경·안쪽 여백을 없애서 글자가 화면 폭을 충분히 쓰게 해줘.

5. 배지와 짧은 라벨
   - "총 0점 보관 중" 같은 배지와 태그는 white-space: nowrap으로 한 줄 유지해줘. 공간이 부족하면 제목 아래 줄로 내려가게.

6. 대시보드 빈 상태 (작품 0점일 때)
   - 상단의 "새 작품 등록" 버튼과 "전체 수장고 열람" 링크는 작품이 1점 이상일 때만 보여줘.
   - 작품이 없을 때는 안내 상자 하나만: 제목 "첫 작품을 수장고에 모셔보세요", 설명 "작품 사진과 기본 정보만 등록하면 작가노트와 캡션까지 이어서 정리할 수 있어요.", 버튼 "첫 작품 등록하기".
   - 위쪽 설명 문구 "세월이 흘러도 변치 않는 ○○님만의 프라이빗 디지털 수장고…"는 휴대폰에서 숨겨줘.
   - 제목 앞 폴더 이모지는 제거 (2단계에서 안 됐다면).

7. 도구 목록 제목 줄

## 6단계. 작품 연결 구조 (가장 중요하고 가장 큰 작업)

**왜 하나요**
지금은 캡션 출력기와 작가노트에서 작품 제목, 연도, 크기, 재료를 매번 새로 입력해야 합니다. 작품을 수장고에 **한 번만 등록하면 모든 도구에서 불러와 쓰게** 만드는 것이 이 서비스가 ChatGPT나 엑셀과 확실히 달라지는 지점이고, 유료 결제의 핵심 이유가 됩니다.

> **매우 중요: 기존 사용자 데이터 보호**
> 무료 플랜 데이터는 사용자 브라우저에 저장돼 있습니다. 데이터 구조를 바꾸다가 실수하면 이미 쓰고 있는 작가들의 기록이 사라질 수 있어요.
> 그래서 이 단계는 **반드시 ① 계획만 받기 → ② 작가님이 읽고 승인 → ③ 실행** 순서로 진행하세요. 계획을 받은 뒤 이해가 안 되는 부분이 있으면 이 문서와 계획을 Claude에게 보여주고 물어보셔도 됩니다.

**할 일 목록**
- [ ] (6-1) 계획 받기: 현재 데이터 구조 분석 + 새 구조 설계 + 기존 데이터 변환 방법
- [ ] (6-2) 작품 정보 하나로 통합 (제목 국/영문, 연도, 크기, 호수, 재료 국/영문, 가격, 비매품 여부, 이미지)
- [ ] (6-2) 캡션 출력기에서 "수장고에서 작품 불러오기"
- [ ] (6-2) 작가노트에서 "수장고에서 작품 불러오기"
- [ ] (6-2) 캡션·작가노트에서 새로 입력한 작품을 수장고에 저장할지 묻기
- [ ] (6-2) 작품 상세 화면에서 연결된 캡션·작가노트 함께 보기
- [ ] (6-2) 기존 데이터 자동 변환 + 변환 전 자동 백업

**안티그래비티 지시문 (6-1: 계획만)**

```
docs/개선작업.md의 6단계 중 6-1(계획)만 진행해줘. 이번에는 코드를 절대 수정하지 말고 계획서만 작성해.

목표: 작품을 "나의 작품 수장고"에 한 번 등록하면, 전시 캡션 출력기와 작가노트&SNS에서 그 작품 정보를 불러와 다시 입력하지 않아도 되게 만들기.

1. 현재 작품 정보, 캡션, 작가노트가 각각 어디에 어떤 구조로 저장되는지 (무료 플랜 브라우저 저장소, 유료 플랜 클라우드 각각)

6. 작업을 몇 개의 작은 단계로 나눌지, 각 단계에서 무엇을 확인해야 하는지
7. 예상되는 위험과 대비책

- 작품 상세 화면에서 연결된 캡션·작가노트가 보이는지
- 휴대폰과 PC에서 각각 확인

**8-1. 포트폴리오 PDF 자동 생성**
```
기능: 포트폴리오 PDF 자동 생성
- 수장고에 등록된 작품 중 원하는 작품을 골라 순서를 정하면, 표지(작가 이름, 연락처) + 작가 소개 + CV + 작품 페이지(이미지, 제목, 연도, 크기, 재료, 작가노트 요약)로 구성된 PDF를 만들어줘.

기능: HWP·Word 내보내기

- 한글 파일 생성이 기술적으로 어려우면 가능한 방법(hwpx 형식 등)과 한계를 먼저 알려줘.

```

**8-3. 지원사업 제출 패키지 + 마감 알림**
```
기능: 지원사업 제출 패키지
- 작가가 지원사업 이름, 마감일, 필요 서류(CV, 작가노트, 작품 목록, 작품 이미지, 활동 계획서 등)를 등록하면, 수장고에 있는 자료로 체크리스트를 만들고 서류를 한 번에 묶어 내려받게.
- 마감 [7]일 전, [1]일 전에 알림 (이메일 또는 사이트 안 알림. 가능한 방법을 제안해줘).
- 유료 플랜 기능으로 표시. 마감 일정 등록과 체크리스트는 무료로 둬도 좋음 (자주 방문하게 만드는 장치).
```

**8-4. 작품 이력·위치 관리**
```
기능: 작품 이력·위치 관리
- 작품마다 상태(보유 중 / 전시 중 / 대여 중 / 위탁 중 / 판매됨), 현재 위치(작업실, ○○갤러리 등), 전시 이력(전시명, 장소, 기간), 판매 정보(구매자, 날짜, 금액), 소장처를 기록.
- 대시보드에 "지금 밖에 나가 있는 작품" 요약 표시.
- 판매됨으로 바꾸면 창작 가계부에 수입으로 기록할지 묻기.
- 전시 이력은 CV의 전시 경력에 자동으로 불러올 수 있게.
```

**8-5. 작품 보증서와 계약서 양식**
```
기능: 작품 보증서와 판매·위탁 계약서 양식
- 작품 정보로 작품 보증서(Certificate of Authenticity)를 자동 생성: 작품 이미지, 제목, 연도, 크기, 재료, 작가 서명란, 발급일, 고유 번호.
- 판매 계약서, 갤러리 위탁 계약서 기본 양식을 작품·작가 정보로 채워서 제공.
- 계약서 양식 하단에 "참고용 양식이며, 중요한 계약은 법률 전문가의 검토를 받으세요." 안내 표시.
```

**8-6. 종합소득세 신고용 자료 정리**
```
기능: 종합소득세 신고용 자료 정리
- 창작 가계부 데이터로 연도별 수입(소득 유형별, 3.3% 원천징수 내역 포함)과 지출(항목별) 요약표를 만들어 엑셀/PDF로 내려받게.
- 세무사에게 전달하거나 홈택스 신고 시 참고할 수 있는 형태로.
- "참고용 자료이며, 실제 신고는 세무 전문가와 확인하세요." 안내 표시.
```

**8-7. 예술활동증명용 활동 내역 정리**
```
기능: 예술활동증명용 활동 내역 정리
- 수장고에 기록된 전시 이력, 출강 기록, 작품 판매 내역을 기간별로 모아 활동 내역 목록과 증빙 자료 체크리스트를 만들어줘.
- 실제 신청 기준과 필요 서류는 한국예술인복지재단 안내를 따르도록 "최신 기준은 재단 홈페이지에서 확인하세요" 안내와 링크 표시.
```

**확인 방법**
- 기능마다 실제 작가 입장에서 처음부터 끝까지 한 번 써보기
- 무료/유료 구분이 의도대로 동작하는지
- 만들어진 파일(PDF, Word, 한글)을 실제로 열어서 깨지지 않는지

## 부록 B. 홍보 방향 (참고)

코드 작업과 별개로, 5단계(공유 노출)까지 마친 뒤 시작하면 좋습니다.

- **용량이 아니라 상황을 말하기**: "지원사업 마감 전날 밤, CV와 계획서를 10분 만에", "전시 캡션 30점, 인쇄까지 한 번에"처럼 작가가 겪는 장면으로.
- **시즌 활용**: 11~12월 미대 졸업전시 시즌에는 졸업 예정자 대상 캡션 무료 출력을 앞세우기. 연초 지원사업 공고 시즌에는 CV·계획서 기능을, 아트페어 시즌에는 캡션·가격표를.
- **베타 작가 프로그램**: Pro 평생 할인을 주고 실제 후기를 받기. 후기 섹션 문제도 함께 해결됩니다.
- **채널**: 인스타그램(캡션 출력 전후를 보여주는 짧은 영상이 가장 직관적), 네이버 카페·블로그(작가 커뮤니티).
- **무료 자료 배포**: "전시 캡션 규격 가이드", "작가 CV 양식" 같은 자료를 나눠주고 가입으로 연결.
- **만든 사람의 이야기**: 직접 붓으로 쓴 로고처럼, 작가의 불편을 아는 사람이 만든 도구라는 진정성을 앞세우기.
- **장기적으로**: 미술학원, 문화센터, 레지던시, 미대 등 기관 단위 판매도 검토.
