## 1. 개편 배경 및 목적
- **기존 문제점:** 대시보드 메인 6열 테이블에 있던 `[보관된 기록]` (`[작가노트] [인스타] [블로그]`) 컬럼은 실제 작가의 자산 관리 및 비즈니스 현황을 파악하기에 직관적이지 못함.
- **개선 목표:**
  1. 미술관/갤러리 표준 소장 관리 체계에 맞추어 **`작품 상태`** 컬럼으로 전면 교체.
  2. 한눈에 어떤 작품이 판매되었고(`🔴 판매 완료`), 비매품인지(`🔵 소장품 NFS`), 보관 중인지(`🟢 보관 중`), 전시 중인지(`🟡 전시·위탁 중`) 즉각 파악 가능하도록 배지 표준화.
  3. 작가노트 작성 여부는 작품명 옆에 단정한 펜 아이콘(`📝 노트`)으로 심플하게 유지하여 가독성 확보.

---

## 2. 세부 변경 내역

### 1) 데이터 모델 표준화 (`src/utils/artworkModel.js` & `src/utils/archiveStorage.js`)
- `ARTWORK_STATUS` 표준 상수 도입:
  - `available`: 보관 중 (판매 가능)
  - `sold`: 판매 완료 (컬렉터 소장)
  - `nfs`: 소장품 (NFS / 비매품)
  - `exhibited`: 전시·위탁 중
- `getArtworkStatusMeta(status)` 헬퍼 함수 제공 (`label`, `shortLabel`, `badgeClass`, `dot` 일관성 보장).
- `normalizeArtwork` 함수에서 하위 호환성 자동 추론 (`status`가 없던 과거 데이터도 `isSold`, `isNfs`를 통해 완벽 복원).
- Supabase 클라우드 동기화 및 로컬 스토리지에 `status` 필드 보존.

### 2) 대시보드 테이블 UI 개편 (`src/components/Dashboard.jsx`)
- PC/태블릿 6열 테이블 헤더: `<th>보관된 기록</th>` ➔ `<th>작품 상태</th>`
- 테이블 행:
  - 작품명 옆에 작가노트 보관 시 `📝 노트` 인디케이터 표기.
  - 5번째 열에 단정한 컬러 뱃지(`🟢 보관 중`, `🔴 판매 완료`, `🔵 소장품 NFS`, `🟡 전시·위탁`) 렌더링.
- 모바일 카드 뷰:
  - 카드 하단에 상태 배지 (`🟢 보관 중` 등) 및 작성일자 배치.

### 3) 디지털 수장고 모달 및 명패 개편 (`src/components/ArchiveStudio.jsx`)
- 새 작품 등록 / 정보 수정 모달:
  - 4개 원클릭 상태 선택 세그먼트 버튼(`🟢 보관 중`, `🔴 판매 완료`, `🔵 소장품 NFS`, `🟡 전시·위탁 중`) 탑재.
  - 소장품(NFS) 선택 시 가격창 자동 비활성화, 판매 완료 시 판매가 입력 안내 문구 동적 전환.
- 미술관 표준 캡션 명패 (`archive-caption-plaque`):
  - 작가명 우측에 현재 작품 상태 배지 단정하게 노출.
- 상단 필름스트립:
  - 썸네일 제목 옆에 상태 도트(`🟢`, `🔴`, `🔵`, `🟡`) 표기.

### 4) 연계 스튜디오 수장고 모달 동기화 (`StatementStudio.jsx`, `CaptionStudio.jsx`)
- 작가노트 및 캡션 스튜디오에서 "수장고에서 작품 불러오기" 시에도 작품 상태 배지가 표시되어 어떤 작품인지 즉각 식별 가능.
